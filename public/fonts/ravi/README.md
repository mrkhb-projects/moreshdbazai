# فونت راوی (Ravi) — Commercial Font

این پوشه محل قرارگیری فایل‌های وب‌فونت **راوی** (تولید [fontiran.com](https://fontiran.com)) است که
فونت اصلی رابط کاربری «مرشد بازاری» است.

## چرا فایل‌های فونت در گیت نیستند؟

راوی یک فونت **تجاری/مالکیتی (Commercial/Proprietary)** است، نه متن‌باز. چون مخزن این پروژه
روی گیت‌هاب **Public** است، فایل‌های باینری فونت (`*.woff2`) عمداً در `.gitignore` قرار گرفته‌اند
تا مجوز فونت نقض نشود. این فایل فقط به‌عنوان مستندسازی ساختار پوشه باقی مانده است.

## برای اجرای محلی یا دیپلوی، این فایل‌ها را اینجا قرار دهید:

```
public/fonts/ravi/Ravi-Regular.woff2    (وزن 400)
public/fonts/ravi/Ravi-Medium.woff2     (وزن 500)
public/fonts/ravi/Ravi-SemiBold.woff2   (وزن 600)
public/fonts/ravi/Ravi-Bold.woff2       (وزن 700)
public/fonts/ravi/Ravi-Black.woff2      (وزن 800/900)
```

این فایل‌ها باید از یک منبع دارای لایسنس معتبر (مثلاً خرید از fontiran.com یا نمایندگان رسمی
آن) تهیه شوند. تا زمانی که این فایل‌ها موجود نباشند، مرورگر به‌طور خودکار به فونت‌های سیستمی
تعریف‌شده در `--font-sans` (در `app/globals.css`) سقوط می‌کند و سایت بدون خطا اجرا خواهد شد؛
فقط تایپوگرافی اختصاصی راوی نمایش داده نمی‌شود.

تعریف `@font-face` مربوطه در `styles/fonts.css` قرار دارد.
